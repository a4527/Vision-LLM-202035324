# 책상 주변 음성 도우미

Project03 | Vision-LLM 융합 시청각 멀티모달 시스템

## 1. 무엇을 만드는가

- 카메라에 보이는 물건에 대해 음성으로 질문하는 도우미다.
- 예를 들어 “컵이 화면 어느 쪽에 있어?”라고 질문한다.
- YOLO, Whisper, Gemma, Piper를 순서대로 연결했다.
- main.py 하나로 실행한다. v는 질문 시작, q는 종료다.

## 2. 전체 처리 순서

- YOLO가 카메라 영상에서 물건을 탐지한다.
- 탐지 결과를 “cup이 화면 왼쪽에 있습니다” 같은 문장으로 바꾼다.
- v를 누르면 5초간 녹음하고 Whisper로 질문을 텍스트로 바꾼다.
- Gemma가 질문과 탐지 결과로 답변을 만들고 Piper가 읽어 준다.

## 3. 위치를 구하는 방법

- 탐지 박스의 왼쪽과 오른쪽 좌표를 더해 2로 나누면 중심을 구할 수 있다.
- 중심이 화면 너비의 1/3보다 작으면 왼쪽이다.
- 1/3 이상이고 2/3보다 작으면 가운데, 나머지는 오른쪽이다.
- 실제 거리를 계산하는 방식은 아니며 화면상 위치만 설명한다.

## 4. 코드에서 볼 함수

- detections_to_text(): 탐지 결과를 물건 이름과 위치 문장으로 바꾼다.
- speech_to_text(): 마이크로 녹음하고 Whisper의 질문 텍스트를 읽는다.
- ask_gemma(): 탐지 결과와 질문을 함께 넣어 답변을 만든다.
- text_to_speech(): Piper로 답변 음성을 만들고 스피커로 재생한다.

## 5. 장비 시연 순서

- config.json에서 모델 경로와 장치를 확인하고 main.py를 실행한다.
- 컵을 왼쪽에 놓고 v를 누른 뒤 위치를 질문한다.
- 보이는 물건의 종류와 탐지되지 않은 물건도 질문한다.
- 답변이 끝나면 카메라가 다시 움직인다. 실제 장비 시연은 별도로 진행한다.

## 6. 한계와 배운 점

- 질문을 순서대로 처리하므로 음성 대화 중에는 카메라 화면이 잠시 멈춘다.
- YOLO의 탐지 오류가 답변에도 영향을 줄 수 있다.
- 이미지를 직접 Gemma에 주지 않아 색상과 글자는 알 수 없다.
- 탐지 결과를 문장으로 바꿔 언어 모델에 전달하는 방법을 적용했다.

코드와 문서 정리에 생성형 AI의 도움을 사용했다. 실제 장비 성능은 아직 측정하지 않았다.
