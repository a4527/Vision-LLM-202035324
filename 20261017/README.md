# 20261017 — 농구공 외곽선 검출과 선택

`02_Computer-Vision.ipynb`의 **H. Contour Detection** 마지막 농구공 실습을 하나의 Python 파일로 정리했다. 목표는 농구공 색상 마스크에 형태학적 연산을 적용하고, 외곽선을 검출한 뒤 농구공에 해당하는 외곽선 하나를 선택하는 것이다.

## 실행 방법

필요한 패키지는 NumPy와 OpenCV이다. Python 3 환경에서 다음과 같이 설치하고 저장소 루트에서 실행한다.

```bash
python3 -m pip install numpy opencv-python
python3 20261017/20261017-assignment.py
```

기본 입력은 저장소에 포함된 `src/images/basketball_crop.jpg`이다. 파일 위치를 기준으로 경로를 계산하므로 `20261017` 폴더 안에서 실행해도 된다. 노트북을 먼저 실행할 필요는 없다.

결과는 기본적으로 `20261017/outputs/`에 저장된다. 화면이 없는 환경에서도 기본 실행이 가능하며, GUI가 지원되는 환경에서는 `--show`로 비교 창을 열 수 있다. 창에서 아무 키나 누르면 종료한다.

```bash
python3 20261017/20261017-assignment.py --show
python3 20261017/20261017-assignment.py --image src/images/basketball_crop.jpg --output-dir /tmp/ball-results
```

`--image`와 `--output-dir`에 직접 지정하는 상대 경로는 명령어를 실행한 위치를 기준으로 해석한다. GUI가 필요 없는 별도 환경에서는 `opencv-python` 대신 `opencv-python-headless`를 설치할 수 있다. 두 OpenCV 패키지를 동시에 설치하지 않는다.

## 처리 과정과 선택 이유

### 1. 독립 실행을 위한 입력 마스크 생성

노트북 앞부분에서 생성한 `mask_enhanced`가 필요하므로 해당 전처리도 포함했다. 이미지를 LAB 색공간으로 바꾸고 L 채널에 CLAHE(`clipLimit=3.0`, `tileGridSize=(8, 8)`)를 적용한다. 색상 채널 a, b는 유지하며 밝기 대비를 국소적으로 보정한다. 이후 노트북과 같은 LAB 하한 `[70, 130, 70]`, 상한 `[180, 230, 185]`로 `cv2.inRange`를 적용해 0과 255로 이루어진 이진 마스크를 만든다. 이 값은 OpenCV의 8비트 LAB 표현을 기준으로 한다.

### 2. 타원형 5×5 커널, Opening 1회 → Closing 3회

농구공은 둥근 물체이므로 사각형보다 방향에 따른 차이가 적은 타원형 커널을 사용했다. 5×5 크기는 작은 노이즈와 틈을 처리하면서 큰 형태는 유지하려는 선택이며, 노트북 H의 농구공 실습과 같은 설정이다.

- **Opening 1회:** 침식 후 팽창하여 작은 전경 노이즈와 가느다란 연결을 제거한다. 반복을 늘리면 공의 유효한 영역도 사라질 수 있어 1회로 두었다.
- **Closing 3회:** Opening 결과에 팽창 후 침식을 적용해 작은 구멍과 끊긴 영역을 연결한다. 농구공의 검은 무늬나 색상 분할 과정에서 생긴 작은 틈을 줄여 큰 연결 영역을 얻기 위한 설정이다.

Closing을 원래 마스크에 따로 적용하지 않고 **Opening의 출력에 순차 적용**한다. 노이즈를 먼저 줄여야 이후 팽창 단계에서 불필요한 영역이 연결될 가능성을 낮출 수 있다. OpenCV에서 `iterations=3`은 팽창 3회 후 침식 3회를 의미하며, Closing 전체를 단순히 세 번 호출한다는 뜻은 아니다.

이 횟수가 모든 영상에서 최적이라는 의미는 아니다. Closing이 강하면 배경과 공이 붙을 수 있고, Opening이 강하면 공 일부가 없어질 수 있으므로 저장한 단계별 마스크로 확인해야 한다.

### 3. 외곽선 검출

`cv2.findContours`에 Closing 결과를 전달한다.

| 설정 | 선택 이유 |
| --- | --- |
| `cv2.RETR_EXTERNAL` | 공 내부 무늬의 경계보다 물체 바깥 테두리가 필요하므로 최외곽 경계만 검출한다. |
| `cv2.CHAIN_APPROX_SIMPLE` | 직선 구간의 중간 좌표를 생략해 저장할 점을 줄이면서 외곽선 형태를 표현한다. |

검출한 전체 외곽선을 초록색으로 그려 선택 전 후보를 확인할 수 있게 했다.

### 4. 최대 면적 외곽선 선택

면적이 0인 점·선을 제외한 후보 중 `max(candidates, key=cv2.contourArea)`로 면적이 가장 큰 외곽선을 선택한다. 제공된 잘린 농구공 이미지에서 공이 주요한 큰 색상 영역이고, 남은 노이즈는 작은 영역이라는 가정을 사용한다.

둘레는 가늘고 길거나 경계가 불규칙한 노이즈에서도 커질 수 있으므로, 내부 영역이 넓은 농구공을 선택하기 위해 **둘레보다 면적**을 기준으로 삼았다. 이는 색상과 크기를 이용한 선택이며 농구공의 의미를 인식하는 분류기는 아니다. 비슷한 색의 큰 배경이나 여러 공이 있으면 잘못 선택할 수 있다.

선택한 외곽선 내부를 `cv2.FILLED`로 채워 최종 마스크를 만든다. 따라서 내부의 구멍도 포함한 하나의 영역이 된다. 이 마스크와 보정된 컬러 이미지를 `cv2.bitwise_and`로 결합하고 외곽선은 빨간색으로 표시한다. 외곽선이 없으면 빈 마스크와 검은 결과 이미지를 저장하고 안내 문구를 출력한다.
